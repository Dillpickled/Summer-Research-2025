# Do AI Dream of Real Images?

An evaluation of how well deep learning image classifiers detect AI-generated images.

Summer research project (2025) at The Chinese University of Hong Kong.
Author: Dillon Adli Gunawan · Supervisor: Prof. Irwin King

## Project

GANs and latent diffusion models now produce images that are hard to tell apart by eye, but the two
families leave different artefacts behind. This project fine-tunes two standard image classification
backbones — **ResNet50** (CNN) and **ViT-B/16** (Vision Transformer) — into binary real/fake
detectors, and compares them head to head.

Three training sets (10,000 images each, 50/50 real vs. generated) are paired with the two
backbones, giving **6 detectors**:

| Training set | Generated half | Detectors |
| --- | --- | --- |
| GAN | 5,000 GAN images | `CNN GAN`, `ViT GAN` |
| Diffusion | 5,000 diffusion images | `CNN Diff`, `ViT Diff` |
| Hybrid | 2,500 GAN + 2,500 diffusion | `CNN Hyb`, `ViT Hyb` |

Each detector is tested on both a GAN test set and a diffusion test set (2,000 images each) — so
every model is also evaluated *cross-architecture*, on generator types it never trained on. Grad-CAM
heatmaps are then used to inspect which image regions drive the CNNs' decisions.

Data comes from two public studies: GAN and real images from Wang et al. (2020), *CNN-generated
images are surprisingly easy to spot... for now*; latent diffusion images from Corvi et al. (2023),
*On the detection of synthetic images generated by diffusion models*.

## Key findings

Overall accuracy across both test sets (percentages):

| Model | Accuracy | Real Acc | AI Acc | FP | FN |
| --- | --- | --- | --- | --- | --- |
| CNN GAN | 84.4 | 99.5 | 69.3 | 0.5 | 30.7 |
| CNN Diff | 78.05 | 99.0 | 57.1 | 1.0 | 42.9 |
| **CNN Hyb** | **96.8** | 99.8 | 93.8 | 0.2 | 6.2 |
| ViT GAN | 70.15 | 97.7 | 42.6 | 2.3 | 57.4 |
| ViT Diff | 68.45 | 97.4 | 39.5 | 2.6 | 60.5 |
| ViT Hyb | 86.7 | 89.1 | 84.3 | 10.9 | 15.7 |

- **CNNs beat ViTs** at this task across every training set, with far fewer false negatives.
- **Detectors do not transfer between generator families.** A diffusion-trained CNN drops to 61.1%
  on GAN images; a GAN-trained ViT drops to 51.1% on diffusion images.
- **Hybrid training generalises without sacrificing specialisation.** `CNN Hyb` reaches 99.8% on GAN
  images and 93.8% on diffusion images, matching or beating the specialised detectors on their own
  home turf.
- **Errors are almost entirely false negatives.** Real accuracy stays above 89% everywhere; the
  detectors fail by letting fakes through, not by flagging real photos.
- **Grad-CAM shows hybrid models look at more of the image.** Hybrid-trained heatmaps reproduce the
  hotspots of the specialised models *and* add large regions the specialised models ignore.

Per-test-set tables, sample images, heatmaps and full discussion are in [Report/Report.pdf](Report/Report.pdf);
[Report/Poster.pdf](Report/Poster.pdf) is the poster summary.

## Setup

Requires an NVIDIA GPU (the training notebooks hardcode `cuda`).

```bash
conda create -n dl python=3.11
conda activate dl
# pick the CUDA build that matches your driver: https://pytorch.org/get-started/locally/
pip install torch torchvision --index-url https://download.pytorch.org/whl/cu121
pip install jupyter numpy matplotlib opencv-python pillow
```

### Data

Datasets are not included — download them from the two source studies and arrange each split as an
`ImageFolder` tree. **Class order matters: `0` = real, `1` = fake.**

```
Train/
  0_real/
  1_fake/
Test/
  0_real/
  1_fake/
```

### Running

Every notebook has placeholder strings (`"Enter path to ..."`) that must be filled in first.

1. **Train** — open `CNN_Train.ipynb` or `ViT_Train.ipynb`, set `train_path` and `test_path`, run
   all cells. Both use 224×224 inputs, ImageNet normalisation, `BCEWithLogitsLoss`, Adam
   (`lr=2e-4` for the CNN, `1e-4` for the ViT) and `ReduceLROnPlateau`. The final cell saves the
   weights with `torch.save(model.state_dict(), ...)` — update that path too.
2. **Evaluate** — open `Accuracy_Test.ipynb`, choose the architecture in `create_model('CNN'|'ViT')`,
   point it at the `.pth` checkpoint and a test set. It prints true/false positives and negatives.
   To measure cross-architecture transfer, keep the checkpoint and swap the test set.
3. **Explain** — open `CNNGradCam.ipynb`, point it at a CNN checkpoint and a single image. It prints
   the prediction and saves the heatmap overlay. The Grad-CAM target layer is `layer4.1.conv2`.
